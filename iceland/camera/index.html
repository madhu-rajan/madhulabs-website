📸 Camera Dry-Run & Eclipse-Day Playbook (D7000)

Print-friendly one-stop reference
Practice window: ~5–6 PM facing SW (sun ~25°, same as eclipse day). To print: unlock this page → Cmd/Ctrl + P.
🔴 Safety: filter ON before pointing at the sun · Live View only (never the viewfinder) · eyes = eclipse glasses only.

1 · Gear

  • 28-300 on the tripod, zoom to 300
  • ND100000 filter ONLY — nothing stacked (no UV/CPL); re-seat dead-flat & tight (fixes the ghost)
  • Lens VR → OFF, focus switch → M

3 · Focus (make-or-break)

  1. Live View ON, center the sun.
  2. Magnify 100% on the sun's edge → turn the focus ring razor-sharp.
  3. Tape it — a strip lengthwise bridging ring + fixed barrel (not a wrap). Tape the zoom ring at 300 too.

4 · Exposure

Start ~1/500s → blown white = faster (1/1000+) · dim = slower (1/250, 1/125). Low sun → likely 1/125–1/500. Goal: a defined disk, bright not blown. Write down the shutter speed.

5 · Kill the ghost

Only ND100000 (no stacking) + seated flat. Test: put the sun off-center → if the dark crescent moves/vanishes it's optical (harmless); if it stays glued to the disk, re-seat the filter.

6 · JJC remote (full recipes in the next section)

HOLD = fire now · START/STOP = run program. Test: INTVL 5s, N 5. Partial time-lapse: INTVL 3:00, N --. Totality: CH drive + AEB (BKT 3F, 2.0 EV), base ~1/125, slide-lock HOLD.

7 · Tripod aiming

Tilt the ball head up ~25°, lock firmly (front-heavy lens). Keep light ball friction to nudge-track the drifting sun (pan sideways, small nudges vertical).

8 · Two-lens comparison

Shoot the sun at 300mm on the 28-300 (native 77mm), then move the ND100000 to the 18-300 via the 67→77 ring, shoot again → compare sharpness at 100%. Use only the sharper lens on Aug 12.

🌑 Totality in full — AEB + Continuous on the D7000
Goal: in the ~90 seconds, grab a range of corona exposures hands-free, then look up. Exact D7000 setup:
  1. Release-mode dial (top-left, under the mode dial) → CH (continuous high).
  2. M · ISO 100 · f/8 · filter OFF · focus taped at ∞.
  3. Turn on bracketing: hold the BKT button (front-left of the body) + turn the rear main dial to 3F (3 frames); turn the front sub-dial to 2.0 EV. → a 3-shot bracket over 4 stops.
  4. Custom menu: e5 Auto-bracketing set → "AE only" (bracket exposure, not flash) · e6 (mode M) → "Flash/speed" so it brackets the shutter speed and keeps f/8 fixed.
  5. Set the base shutter to a mid-corona value — start ~1/125s.
  6. Fire with the remote: slide-lock the HOLD button (or INTVL 0:02 / N 15 on START/STOP). In CH + AEB it rattles off the 3-frame bracket; keep firing to repeat sets.
Cover the fuller corona (optional): one 3-frame ±2EV set (e.g. 1/250 · 1/125 · 1/60) nails the inner corona + diamond ring. For the faint outer corona, flick the rear dial to a new base between bursts — e.g. a set at 1/125, then 1/15, then 1s — spanning ~1/250 → 2s.

❗ Reality check: fire one or two AEB bursts in the first ~30 s, then put the remote down and LOOK UP. It's your 30th anniversary — the memory beats a 12th frame. A couple of bracketed bursts of the diamond ring + inner corona is a beautiful, plenty-good first-totality result.
Practice before Aug 10
  1. Program fluency: INTVL 5s, N 5, START → watch 5 frames fire.
  2. Partial time-lapse: INTVL 3:00, N --.
  3. Totality mechanics: filter ON in the dry run, set CH + AEB (3F, 2.0), fire a bracketed burst hands-free while you look up.
  4. Bulb: camera to bulb, JJC LONG 20s → confirm a 20-second exposure.
  5. Reflex: HOLD = fire now · START/STOP = run the program.
